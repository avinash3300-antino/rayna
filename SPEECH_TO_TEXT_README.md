# 🎤 Speech-to-Text Integration for Rayna Chatbot\n\nThis document explains the Speech-to-Text functionality implemented in the Rayna Tours chatbot.\n\n## 🌟 Features\n\n### ✅ **Browser Web Speech API (Free & Fast)**\n- **Real-time transcription** as you speak\n- **No API keys required** - works completely client-side\n- **Multiple languages supported** (English, Arabic, Hindi, etc.)\n- **Instant results** - no server processing needed\n- **Privacy-friendly** - audio never leaves the browser\n\n### ⚡ **OpenAI Whisper API (Premium & Accurate)**\n- **Superior accuracy** especially for accented speech\n- **Better noise handling** for busy environments\n- **Supports 50+ languages** with high accuracy\n- **Requires OpenAI API key** (costs ~$0.006 per minute)\n\n## 🛠️ Implementation\n\n### Files Added:\n```\nfrontend/src/\n├── hooks/\n│   ├── useSpeechToText.ts     # Browser Web Speech API hook\n│   └── useWhisperSTT.ts       # OpenAI Whisper API hook\n├── components/ui/\n│   ├── SpeechButton.tsx       # Reusable speech button component\n│   └── SpeechDemo.tsx         # Demo component for testing\n├── app/api/speech-to-text/\n│   └── route.ts               # Next.js API route for Whisper\n└── components/chat/\n    └── ChatInput.tsx          # Updated with speech functionality\n```\n\n### Updated Components:\n- **ChatInput.tsx**: Now includes microphone button with speech-to-text\n- Added visual feedback (pulsing red when listening)\n- Real-time transcript display\n- Error handling and user feedback\n\n## 🚀 Quick Start\n\n### 1. **Browser API (No Setup Required)**\nThe microphone button appears automatically in supported browsers (Chrome, Edge, Safari):\n\n1. Click the 🎤 microphone button in the chat input\n2. Allow microphone permissions when prompted\n3. Speak your message clearly\n4. Click the microphone again to stop and send\n\n### 2. **Whisper API (Optional Premium)**\nTo enable high-accuracy Whisper transcription:\n\n1. Get an OpenAI API key from https://platform.openai.com/api-keys\n2. Create `frontend/.env.local`:\n   ```bash\n   OPENAI_API_KEY=your_openai_api_key_here\n   ```\n3. Restart your development server\n4. Change mode to 'whisper' in SpeechButton component\n\n## 🎯 Usage Examples\n\n### Basic Integration:\n```tsx\nimport { useSpeechToText } from '@/hooks/useSpeechToText';\n\nfunction MyComponent() {\n  const {\n    transcript,\n    isListening,\n    startListening,\n    stopListening\n  } = useSpeechToText();\n\n  return (\n    <div>\n      <button onClick={isListening ? stopListening : startListening}>\n        {isListening ? 'Stop' : 'Start'} Listening\n      </button>\n      <p>You said: {transcript}</p>\n    </div>\n  );\n}\n```\n\n### Advanced Configuration:\n```tsx\nconst {\n  transcript,\n  isListening,\n  startListening,\n  stopListening,\n  error\n} = useSpeechToText({\n  continuous: true,        // Keep listening after pauses\n  interimResults: true,    // Show partial results\n  language: 'en-US'        // Set language (en-US, ar-SA, hi-IN, etc.)\n});\n```\n\n## 🌍 Language Support\n\n### Browser API Languages:\n- **English**: `en-US`, `en-GB`, `en-AU`\n- **Arabic**: `ar-SA`, `ar-EG`, `ar-AE`\n- HTTPS (required for microphone access)\n- Enable microphone permissions in browser settings\n\n### \"Speech recognition not working\":\n- Check internet connection (browser API needs connection)\n- Speak clearly and close to microphone\n- Reduce background noise\n- Try reloading the page\n\n### \"Whisper API errors\":\n- Verify OpenAI API key in `.env.local`\n- Check API key has billing enabled\n- Ensure audio file size < 25MB\n\n### \"Poor accuracy\":\n- Use Whisper API for better accuracy\n- Speak clearly and slowly\n- Use in quiet environment\n- Consider switching language setting\n\n## 🚀 Future Enhancements\n\n### Planned Features:\n- **Voice commands**: \"Book tour\", \"Show Dubai packages\"\n- **Multilingual auto-detection**\n- **Offline speech recognition**
